# ZRdp SVN Bridge 接続別Agent設定と自動起動

更新日: 2026-10-14

Agent設定は接続マネージャーで編集し、RDP接続先・ドメイン・ユーザーの組に紐づける。
接続名の変更では設定を引き継ぐが、別の接続先・ユーザーには引き継がない。
RDP認証後に自動で配置・更新・起動し、設定確認の応答を受けてからProxyを利用可能にする。
自動管理では起動確認・進捗・失敗dialogを表示しない。起動buttonと開発用入力テストもない。
署名は起動条件にせず、Windowsと組織の実行・転送制限、Client自動更新の検証は維持する。

## 設定と接続

1. 接続マネージャーで接続先、ドメイン、ユーザーを入力または履歴から選ぶ。
2. 同じ画面の `Agent設定` buttonを開く。
   この画面は設定専用で、選択した接続に登録済みの宛先だけを表示する。
   マネージャーで接続先・ドメイン・ユーザーを変更すると、開いている設定画面も読み直す。
   未登録接続は空一覧、接続未選択は編集不可になる。画面内に接続切替controlは置かない。
3. 業務利用が許可されたHTTP SVNまたはHTTP TracのIP・ポート・用途を入力し、`登録` を押す。
   登録操作はその完全一致宛先の利用承認を兼ねる。別の承認checkboxや保存buttonはない。
   同じIP・ポートの再登録は用途を更新し、IP・ポートが異なれば新規追加する。
   用途は表示・記録用で、中継動作をSVN／Tracのどちらかに制限しない。
   承認済みSVNとTracが同じIP・ポートなら一件の登録で両方を利用できる。
4. 不要な接続先は一覧で選択し、`削除` を押す。
   登録・削除は暗号化保存され、接続中なら当該接続のAgentへ自動反映する。
   保存成功後だけ一覧を更新し、失敗時は旧一覧と入力を維持する。保存中は二重操作と終了を待つ。
   保存中の接続切替は最後の一件を保留し、元接続への保存成功後に切り替える。
   保存失敗では元接続と入力を残すため、表示中の接続を確認して登録をやり直す。
5. 設定画面を閉じ、RDPを前面にした状態で待つ。通常のログイン後は約5秒の準備待機と
   一秒の入力休止を経て固定自動入力を開始する。フォルダ準備、手動貼付け、EXE選択は不要。
6. `Agent:接続済み`、`Proxy:利用可` と、接続先のAgentトレイiconを確認する。
   API入力受付だけでは成功と扱わず、最新設定の応答を確認する。

未設定または未承認なら、認証後は `Agent:要設定` を表示し、配置・起動・中継を待つ。
設定画面は自動表示しない。接続マネージャーで該当接続を選び、`Agent設定` から登録する。
既存形式1の未関連付け設定と、形式2に残る未承認候補は暗号化保存のまま保全するが、一覧には表示しない。
旧設定を接続先へ推定継承しないため、初回は必要なIP・ポート・用途を当該接続で登録する。
自動起動と設定反映には一覧と同じ登録済み宛先だけを使い、未承認候補はINIへ出力しない。
登録済み宛先がある接続は、非表示の未承認候補を理由に未設定扱いにしない。
最後の登録済み宛先を削除すると起動用設定が空になり、その接続のProxyとAgentを協調停止する。
保存snapshotに残る未承認候補は変更しない。

旧Agentが稼働している初回更新では、トレイから一度終了する。旧console版はCtrl+Cで終了する。
新Agent同士の更新は同じRDP session内で協調停止する。Windowsサービスやログオン自動起動は登録しない。

## 配置と設定変更

Clientと同じフォルダに、信頼できる配布元の同一製品版Client／Agentを置く。
接続前にsession専用の空driveだけを登録し、承認後のworkerが固定EXEと初回INIをreadonlyで公開する。
通常driveとdynamic driveを転送せず、固定 `--rdp-setup` だけを実行する。

接続先は `%LOCALAPPDATA%\ZRdp` に固定する。未配置なら配置、同一二fileなら再利用、
異なる二fileはuser専用 `backup-{GUID}` に保全して上書き更新する。リンク、過大file、
読込不能、backup不能、使用中fileでは更新しない。部分commitは旧二fileへ復旧する。

公開済みdriveは同じRDP中に変更しない。設定変更は限定SVC controlで現在の承認INIだけを渡す。
Agentは全Socketを閉じてINIだけをbackup付きatomic renameで更新し、
channel・tray・singletonを解放した後に固定の自身を再起動する。
新Agentが同じINIを確認するまでProxyを再開しない。削除・承認撤回ではProxyとAgentを協調停止する。
INIの手動読込み・出力は設定画面から除去した。配置用INIは内部で生成する。

設定変更時は既存HTTP streamが終了する。SVN／Tracの処理中には変更せず、
必要な操作は利用者が再実行する。HTTP要求の自動再送やstream resumeは行わない。

## 疎通断と入力停止

Agentの終了または死活断では同じ認証世代だけを復旧対象にし、5秒から最大60秒のbackoffを使う。
起動応答を最大45秒待ち、連続三回の無応答または安定前の疎通断で自動復旧を停止する。
正常疎通が30秒継続した場合だけ失敗数を戻す。部分入力、設定拒否、protocol異常では即座に停止する。
停止後は設定画面で必要な宛先を再登録するか、新しいRDP接続を開始して再準備する。RDP本体は維持する。

対象RDPが前面にない、最小化中、認証警告中なら入力を開始しない。全画面も対象前面なら扱う。
開始後に画面を切り替えた場合やclipboard世代が変わった場合は残りの入力を停止し、戻っても再送しない。
複数sessionの固定入力は一度に一件だけである。自動入力の間はkeyboard・mouse操作を控える。
起動のためWindowsの「ファイル名を指定して実行」が一時的に開き、固定commandを自動入力する。
この画面を利用者が操作する必要はないが、Windows自身の警告は隠さず自動承認しない。
SendInputの直前確認後にも前面切替が重なる競合は残る。
Agentのsetup・通常起動失敗は終了codeと固定診断に記録する。Clientは無応答期限や状態に応じて
タイトルへエラーを表示し、独自の失敗dialogは出さない。setupの終了codeはClientへ即時通知しない。
部分受付でWin／Ctrl／R／V／Enterが押下のまま残った場合は、該当キーを手動で押して離す。

## 保存形式

保存先は `%LOCALAPPDATA%\ZRdpSvnBridge\agent-settings.bin`。
独立形式2の明示的little-endian整数とUTF-16名・接続keyをcurrent-user DPAPIで暗号化する。
形式1は未関連付けとして読み込める。設定は最大16件、宛先は各128件、表示名は64文字、
接続keyは1024 UTF-16単位、平文は64 KiB、暗号化fileは128 KiB以下とする。
RDP履歴Version 3、`client.ini`、password、repository URLの形式は変更しない。

file I/OとDPAPIは一workerの要求一件・結果一件で直列実行する。
破損・復号失敗は空設定と区別し、旧保存fileを上書きしない。
設定名は接続組から内部で決め、編集・切替・設定全体の削除・個別保存を画面に置かない。
未登録の入力は永続化せず、画面を閉じても登録済み設定は変更しない。

実IP、接続key、設定内容、credential、payloadをlogへ出さない。
一時配布INI、接続先INIとbackupは平文であり、user限定ACLで保護する。
不要なbackupやクラッシュ後の一時配布folderの回収は利用者が行う。
同じWindowsユーザーや管理者からの完全防御は保証しない。

入力操作や設定の保護については [セキュリティ](security.md) と [既知の制約](known-limitations.md) を参照する。

## Clientの更新との連動

Client自動更新は同一版のClient／Agentをセットで取得・検証・適用する。
元・候補の二EXEとも同一発行者の署名済みセットが自動更新の前提であり、通常起動の任意署名方針とは区別する。
接続先のAgentは次回RDP認証後、登録済み宛先がある場合だけ既存の固定setupで更新・起動する。
RDP接続中のEXE差替えや強制再接続は行わない。詳細は[セット自動更新](client-updates.md)を参照する。
