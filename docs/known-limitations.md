# ZRdp SVN Bridge 既知の制約

## 対応する通信

対象は、登録したIPv4アドレス・ポートに一致するHTTP方式のSVN／Tracです。
HTTPS、ホスト名、IPv6、HTTP CONNECT、WebSocket、SOCKS、任意のTCP／UDP転送には対応しません。
リダイレクト先がHTTPS、ホスト名、未登録のIP・ポートなら通信できません。

登録はIP・ポート単位で、URLのパスごとの制限ではありません。
同じ宛先上のアクセス権は、SVN／Tracサーバー側の認証と権限で管理してください。
Proxyには独自の認証がなく、同じ開発PCの別プロセスからも接続できます。

一つのClientで最大16 RDP接続、一接続あたり最大8 HTTP通信を扱います。
複数ClientプロセスはProxyポートを共有しないため、同じ基準ポートでは競合します。
一つの接続マネージャーから複数の接続を開始してください。

## Agentの自動起動

RDPのドライブ・クリップボード転送と、接続先でのEXE実行が許可されている必要があります。
登録0件ではAgentを起動しません。Windowsや組織の警告・制限は自動承認や回避をしません。

自動起動は固定のWin＋R、貼り付け、Enterを送信します。
直前の前面・フォーカス確認後にも画面切替が重なる可能性があり、手元の別の画面へ
誤入力・誤実行されるリスクを完全には排除できません。
処理中はRDP画面を前面に保ち、入力やウィンドウ切替を控えてください。
クリップボードは置き換わり、元の内容は復元しません。

部分的に入力が受け付けられた場合は再送しません。
Win／Ctrl／R／V／Enterが押下のまま残った場合は、該当キーを手動で押して離してください。
一度送った実行操作や、配置済みのファイルを取消操作で取り消すことはできません。

Agentをトレイから終了しても、RDP接続中は自動復旧の対象になります。
止めたままにするにはRDPを切断するか、その接続の登録をすべて削除してください。
復旧は有限回で、連続失敗時は停止します。詳しくは [Agent設定](agent-settings.md) をご覧ください。

## 切断と設定変更

切断、Agent再起動、設定変更では既存のHTTP通信が終了します。
途中再開やCommit等の自動再実行はしません。結果が不明な場合は、サーバー側で結果を確認してから
必要な操作を行ってください。

Agentの無応答検出には最大約20秒かかる場合があり、その間の新しいHTTP通信は失敗することがあります。
最初のHTTPヘッダーには30秒の期限、接続後には30分の無通信期限があります。

各RDP接続のSTAと通信状態は分離していますが、Clientプロセス自体は共有します。
プロセス全体の異常終了に対する完全な隔離はありません。
Microsoft ActiveX内部の終了処理が長く待機する可能性もあります。

## 表示と音声

接続前に既存リモートセッションの解像度を自動取得することはできません。
動的解像度を選ぶと、接続先アプリの配置が変化する場合があります。
マイク・音声は接続時に確定し、接続中の変更はできません。

Windows、接続先GPO、音声デバイスの制限によって利用できない場合があります。
ZRdpはその制限を変更しません。

## 設定と更新

DPAPIの保護はWindowsユーザー単位です。同じユーザーとして動く別プロセスや管理者からの
完全な防御を提供するものではありません。
接続先のINIとバックアップは平文で、ユーザー限定のアクセス権で保護します。

Client／Agentの通常起動は署名を必須にしませんが、自動更新には有効な署名と同じ発行者が必要です。
未署名の自前ビルドや署名鍵が変わる更新は、二つのEXEを手動で揃えてください。

二つのEXEを同時に置換するOSレベルのatomic性や、電源断時の完全な自動復旧は保証しません。
失敗時のstageと旧版バックアップは、一括削除せず内容を確認してください。
詳細は [セット更新](client-updates.md) と [セキュリティ](security.md) をご覧ください。
