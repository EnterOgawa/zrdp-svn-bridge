# ZRdp SVN Bridge 設定

接続情報は接続マネージャー、SVN／Tracの宛先は「Agent設定」で登録します。
通常はINIファイルを作る必要はありません。

## 接続情報と保存先

認証が完了した接続について、接続名、接続先、ドメイン、ユーザー名、マイク転送、
リモート音声の再生先を直近10組まで保存します。パスワードは保存しません。
接続名を履歴から選ぶと、これらの設定をまとめて復元します。

| ファイル | 内容 |
|---|---|
| `%LOCALAPPDATA%\ZRdpSvnBridge\connection-history.bin` | 接続履歴 |
| `%LOCALAPPDATA%\ZRdpSvnBridge\agent-settings.bin` | 接続ごとのAgent設定 |

どちらもWindowsユーザー単位のDPAPIで暗号化します。別ユーザーや別PCへファイルだけを
コピーしても使えるとは限りません。同じWindowsユーザーが使う別の配置先のZRdpは設定を共有します。

接続名は64文字までです。同じ接続先・ドメイン・ユーザー名の組は、大小文字を区別せず
一件にまとめます。同じ空でない接続名を再利用すると、最新の接続情報へ更新します。
ドメインとユーザー名は別欄に入力してください。ドメイン欄が空の `DOMAIN\user` は
二項目へ分離し、UPN形式のユーザー名はそのまま扱います。

## Agent設定

設定はRDP接続先・ドメイン・ユーザー名の組ごとに保存します。
接続名を変更しても引き継ぎますが、別の接続先やユーザーには引き継ぎません。

「Agent設定」でHTTP SVN／TracのIPアドレス、ポート、用途を入力して登録します。
登録・削除は自動保存されます。同じIP・ポートを登録すると用途を更新します。
用途は表示用なので、同じIP・ポートのSVNとTracは一件の登録で利用できます。

設定は最大16接続、各接続の宛先は最大128件です。登録0件ではAgentを起動しません。
接続中の変更はAgentへ反映し、既存のHTTP通信を終了して再起動します。
詳しくは [Agent設定](agent-settings.md) をご覧ください。

## 表示と音声

| 表示モード | 動作 |
|---|---|
| 等倍表示（スクロール） | 接続開始時の解像度を維持。既定 |
| Smart Sizing（縮小表示） | 接続先の解像度を変えずに表示を拡大・縮小 |
| 動的解像度（Window追従） | 接続先の解像度をRDP表示領域へ合わせる |

等倍とSmart Sizingでは現在のモニター全体の寸法で接続を開始します。
動的解像度ではRDP表示領域で開始し、ウィンドウ変更後250 msの待機を経て更新します。
既存のリモートセッションの解像度を、接続前に自動取得する機能はありません。
表示モードは接続中にも切り替えられ、起動時は等倍表示へ戻ります。

マイク転送は既定OFF、リモート音声は既定でこのPCに再生します。
音声設定は接続時に確定するため、変更後は新しい接続から反映します。
Windowsや接続先のポリシーによる制限は変更しません。

## client.ini

Proxyの基準ポートや更新確認を変更するときだけ、Clientの横に `client.ini` を置きます。
設定例は [client.ini.example](../config/examples/client.ini.example) にあります。

```ini
[proxy]
port=18080

[update]
enabled=true
repository=EnterOgawa/zrdp-svn-bridge
```

| 設定 | 内容 |
|---|---|
| `[proxy] port` | 最初のRDP接続のProxyポート。ファイルがない場合は18080 |
| `[update] enabled` | `false` でGitHubへの更新確認を停止 |
| `[update] repository` | 更新元。既定は `EnterOgawa/zrdp-svn-bridge` |

明示した `[proxy]` では `port` が必要で、範囲は1～65535です。
`[update]` だけのファイルではProxyの基準ポートは18080になります。
ファイルは最大64 KiB、UTF-8 BOMは任意です。未知の項目、重複、不正な値は拒否します。
Proxy設定の不正ではProxyを停止し、不正な更新設定では更新だけを停止します。

待受アドレスは `127.0.0.1` 固定です。追加のRDP接続には基準ポート＋空き枠を割り当て、
最大16接続まで扱います。割当予定ポートが使用中でも別ポートへ自動切替しません。
SVN／Tracには、RDPウィンドウのタイトルに表示されたポートを指定してください。

Proxy設定はClient起動時に読み込みます。更新設定は確認・取得・適用の各段階で読み直します。
詳細は [セット更新](client-updates.md) をご覧ください。

## AgentのINIと設定の削除

Clientは登録済みの宛先から、接続先の `%LOCALAPPDATA%\ZRdp\agent.ini` を生成します。
通常は手動編集せず、「Agent設定」から変更してください。
[agent.ini.example](../config/examples/agent.ini.example) はファイル形式の説明用です。

```ini
[allowlist]
endpoint.1001=192.0.2.10:80
endpoint.1002=198.51.100.20:8080
```

手動配置で使う場合はAgent EXEの横に置きます。IPv4とポートの完全一致だけを許可し、
ホスト名、CIDR、ワイルドカード、ポート範囲、重複、空設定を拒否します。
上限は128宛先、64 KiBです。不正な設定を一部だけ採用することはありません。

履歴を消去する場合はClientを終了し、`connection-history.bin` だけを削除します。
アンインストール時には履歴とAgent設定の両方を削除するか選べます。
対象は同じWindowsユーザーの全接続分で、削除は元に戻せません。
詳細は [インストーラー](installer.md) をご覧ください。
